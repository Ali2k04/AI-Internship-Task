# Language Detection Model

## Objective

Detect the language of multilingual text using Machine Learning.

## Languages Supported

- English
- Urdu
- Spanish
- French
- German

## Features

- Character-level TF-IDF
- Naive Bayes Classifier
- Model Accuracy
- Confusion Matrix
- Classification Report
- Save Model
- Batch Prediction
- CLI Menu
- Top-2 Predictions
- langdetect Comparison

## Run

Train Model

```bash
python train.py
```

Predict

```bash
python predict.py
```

Batch Prediction

```bash
python batch_predict.py
```

# Fake News Detection System

## Description

This project detects whether a news article is Fake or Real using Machine Learning and Natural Language Processing.

## Technologies

- Python
- pandas
- scikit-learn
- NLTK
- Matplotlib
- Seaborn

## Model

- TF-IDF Vectorizer
- Logistic Regression

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Run

Train:

```bash
python train_model.py
```

Predict:

```bash
python predict.py
```

# 📊 Model Evaluation Dashboard

An interactive Streamlit dashboard that trains and compares multiple machine
learning models on a text-classification task (spam detection) using
**Accuracy, Precision, Recall, and F1-score**.

## ✨ Features

- ✅ Trains 3 models: **Logistic Regression**, **SVM (linear kernel)**, **Naive Bayes**
- ✅ Model comparison table with all 4 metrics
- ✅ Grouped bar chart comparing metrics across models (Plotly)
- ✅ Dropdown to select a model + detailed metric cards
- ✅ **Confusion matrix** heatmap per model (bonus)
- ✅ **ROC curve** with AUC per model (bonus)
- ✅ **Upload your own dataset** (CSV with `text` + `label` columns) and
  retrain live in the app (bonus)
- ✅ **Export metrics as CSV** (bonus)
- ✅ **Dark mode UI** via `.streamlit/config.toml` (bonus)

## 🚀 How to Run

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Train the models (only needs to be run once, or whenever you change the
   dataset):
   ```bash
   python train_models.py
   ```
   This generates `dataset.csv` (a synthetic spam/ham dataset) if it doesn't
   already exist, trains all 3 models, and saves everything under `models/`.

3. Launch the dashboard:
   ```bash
   streamlit run app.py
   ```

4. Open the URL Streamlit prints (usually `http://localhost:8501`).

## 🧠 About the Dataset

Since no specific dataset from a previous task was provided, this project
ships with a **synthetic spam-detection dataset** (`dataset.csv`, ~470 rows)
generated in `utils.py`. It mixes spam/ham sentence templates, includes some
deliberately ambiguous examples, and injects light label noise (~9%) so the
models produce realistic, non-perfect scores rather than a suspicious 100%.

**To use a real dataset instead** (sentiment analysis, spam detection, fake
news detection, etc.):
- Replace `dataset.csv` with your own file containing a `text` column and a
  `label` column, then re-run `python train_models.py`, **or**
- Use the "Upload my own CSV" option directly inside the dashboard sidebar —
  no retraining script needed, it trains live.

## 🔧 How It Works

- **`utils.py`** — `generate_spam_dataset()` builds the demo data;
  `train_and_evaluate()` runs a `TfidfVectorizer` + one of the three
  scikit-learn classifiers and computes
  `accuracy_score`, `precision_score`, `recall_score`, `f1_score` from
  `sklearn.metrics`; `save_artifacts()` / `load_artifacts()` persist results
  with `joblib` so the app doesn't retrain on every page load.
- **`train_models.py`** — one-time CLI script that calls the above and
  prints the comparison table to the terminal.
- **`app.py`** — the Streamlit UI: comparison table, bar chart, model
  selector, confusion matrix, ROC curve, CSV export, and the "upload your
  own data" workflow (which reuses the exact same `train_and_evaluate()`
  function, so results are consistent whether trained via the script or the
  UI).

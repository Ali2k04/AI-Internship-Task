# Multi-Class Sentiment Analysis

## Objective

This project classifies text into four sentiment classes:

- Positive
- Negative
- Neutral
- Mixed

## Libraries

- pandas
- nltk
- scikit-learn
- matplotlib
- seaborn
- joblib

## Machine Learning Model

Logistic Regression

## Feature Extraction

TF-IDF Vectorizer

## Evaluation

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
